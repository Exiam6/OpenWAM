# Prospective evaluation implementation, before any new learned-policy outcomes

The frozen protocol.json is unchanged. This document resolves implementation details and records gates, not outcome-based choices.

- Six finite GPU queues run on cm009 GPUs1–6 only after all nine trainings, the150-scene expert cohort and the development-scene simulator preflight complete. No more than six evaluation GPUs are used, and no training is terminated. The existing two collection slots bring earlier concurrency to8.
- The development smoke uses profile-v3 PCA weights (32microsteps, never a primary checkpoint) and scene seed10 for each task, at most one native action per task. It verifies native eval setup versus expert replay setup, exact repeat reset on identical WebSocket inputs,20D-to-native action conversion, real camera yaw with wrist views/state preserved, and the real SAPIEN contact API. It never tests a heldout learned-policy episode. Queue waits are finite dependencies, not recurring timers.
- Renderer PCI must match the reserved GPU, initial object poses/proprio must match reference within1e-6, and initial mean absolute RGB discrepancy must be≤1 on the0–255 scale. These checks apply before every learned-policy rollout. Failure stops with artifacts retained.
- The native per-task action-step limit is read from upstream. All108 task/condition summaries are required. A task-condition job has9000seconds, a scene600seconds; no automatic retries or replacement after an infrastructure failure. All routes use10 denoising steps and horizon8.
- Action randomness: SeedSequence([scene_seed, policy_seed,811]); pixel noise: SeedSequence([scene_seed, action_step, camera_index,701]). Both recipes are paired across routes. All policy inference state resets at the first action. Actual initial camera poses and any yaw transform are retained.
- Secondary expert-state diagnostics use12 linearly spaced current frames from0 through(n_frames−2), all150 expert trajectories, the3 noise conditions and9 fixed final policies:48,600 one-step predictions. Ground truth is frame+1, as in native training; a hold-current-state baseline is reported. Each policy diagnostic has3600seconds. Rotation is measured in degrees; translation MSE in square metres; gripper error in native units. Closing is a kinematic proxy; physical contacts are only claimed for actual recorded simulator contact events. The saved expert images cannot supply real camera-yaw observations, so yaw is covered only in closed-loop evaluation.
- Primary success intervals use20,000 paired hierarchical bootstrap draws, seed42420, resampling training seeds and scene IDs within tasks. All per-task/seed outcomes remain visible;3 policy seeds do not establish precise population seed variability. Component diagnostic aggregates are secondary descriptive evidence.
- An independent audit reconstructs all5,400 raw episode results and traces, then recomputes the fixed bootstrap with explicit indexing. No inference/refit in the audit. Cohort identity checks include both-group historical seed exclusion, prior recorded image/file hashes and latest60 confirmation hashes; exact identities do not claim unseen categories.
- The dependency gate expires at the fixed pipeline-plan timestamp (48h after main protocol freeze). Each evaluation queue has a fixed64h40min timeout, covering its finite list. No automatic deadline extension or fresh data selection.
